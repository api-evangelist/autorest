# AutoRest

> AutoRest is an open source Microsoft tool (MIT) that generates client libraries for accessing RESTful web services from OpenAPI 2.0 (Swagger) and OpenAPI 3.0 specifications. It is the generator behind the Azure SDKs across C#, Python, Java, TypeScript, Go, PowerShell and Swift, built on a pipeline of npm-distributed plugins. AutoRest is DEPRECATED and retires on 2026-07-01; the recommended successor is TypeSpec.

> Generated by API Evangelist from the project's public GitHub repository on 2026-08-06. AutoRest does not publish an llms.txt of its own — it operates no website or docs host, so there is no origin to serve one from. Everything below was fetched from github.com/Azure/autorest.

## Status

- [Deprecation notice](https://github.com/Azure/autorest/blob/main/readme.md): Deprecated; retirement 2026-07-01; no new features, language generators or plugins.
- [Deprecation tracking issue #5175](https://github.com/Azure/autorest/issues/5175): The public thread carrying the retirement plan.
- [TypeSpec](https://typespec.io/): The named replacement — Microsoft's actively developed API description language and code generation platform.

## Install and run

- [Installing AutoRest](https://github.com/Azure/autorest/blob/main/docs/install/readme.md): `npm install -g autorest`; requires Node.js.
- [Command line interface](https://github.com/Azure/autorest/blob/main/docs/user/command-line-interface.md): `autorest [config-file.md|json|yaml] [options]`; configuration file is the preferred surface, flags override it.
- [Configuration files](https://github.com/Azure/autorest/blob/main/docs/user/configuration.md): Literate Markdown configuration; `readme.md` is the default.
- [Index of AutoRest flags](https://github.com/Azure/autorest/blob/main/docs/generate/flags.md): 106 documented flags, grouped by generator.
- [AutoRest versioning](https://github.com/Azure/autorest/blob/main/docs/install/autorest-versioning.md): CLI / core module / extension version pinning with `--version:` and `--use:`.
- [Docker images](https://github.com/Azure/autorest/blob/main/docs/docker.md): `azsdkengsys.azurecr.io/azuresdk/autorest` and per-language variants.

## Notes for agents

- AutoRest exposes NO HTTP API, no base URL, no authentication surface and no rate limits. It is a locally installed CLI. Any tool that plans to "call the AutoRest API" is mistaken.
- The only credentials AutoRest accepts (`--github-auth-token`, `GITHUB_AUTH_TOKEN`) are for reading OpenAPI input files from private GitHub repositories.
- For new work, generate from TypeSpec instead. AutoRest accepts no new features and retires 2026-07-01.
